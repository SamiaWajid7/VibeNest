# VibeNest 💬

A real-time social messaging platform for building meaningful connections, featuring emotion tracking, compatibility matching, and interactive chat with read receipts.

## ✨ Features

- **Real-time Messaging:** Instant chat with read receipts and typing indicators.
- **Emotion Tracking:** Log and visualize your daily emotions and moods.
- **Compatibility Quiz:** Match with others based on shared values and intentions.
- **Goal Setting:** Create and track daily personal goals.
- **User Authentication:** Secure login and signup powered by Firebase Auth.
- **Media Sharing:** Upload and share images within conversations.
- **User Management:** Block/unblock users for a safe experience.

## 🚀 Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, React Router, Lucide Icons
- **Backend & Database:** Firebase (Authentication, Firestore)
- **Deployment:** (https://vibe-nest-553ea.web.app)

## 📦 Installation

1.  **Clone the repository**
   

2.  **Install dependencies**
    npm install

3.  **Environment Variables**
    Create a .env file in the root directory and add your Firebase configuration:
    VITE_FIREBASE_API_KEY=your_api_key
    VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
    VITE_FIREBASE_PROJECT_ID=your_project_id
    VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
    VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
    VITE_FIREBASE_APP_ID=your_app_id

4.  **Run the development server**
    npm run dev

## 🔧 Usage

1.  Sign up for a new account or log in.
2.  Complete your profile and the compatibility quiz.
3.  Start connecting with other users and send messages in real-time.
4.  Use the emotion tracker and goal-setting features to enhance your personal journey.
